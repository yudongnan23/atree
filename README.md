# atree

**终端里的 Claude Code 会话侧边栏。** 体验向 Claude Desktop 看齐：左边常驻一栏，按 project 分组列出你所有的 Claude 会话；右边是当前选中的 Claude。可以跨 project 切换，也可以在同一个 project 的多个会话之间切换；切走的会话在后台继续运行，切回来还是原样。

```
Agent Tree                     │ ╭ Claude Code ─────────────────────╮
▾ my-app                       │ │ ~/code/my-app                    │
  ◆ 设计文档和实现计划         │ ╰──────────────────────────────────╯
  ● 登录接口排查               │
  ○ 补齐单元测试               │ > 看一下当前项目下的设计文档
  · 依赖升级           10-13   │
  … 更早的 6 个会话            │ ⏺ 我找到了 3 份设计文档……
▾ atree                        │
  ● 侧边栏会话管理器           │ > █
▸ my-api                  3    │
▸ 已归档                  2    │
⌥← 回到侧栏  ⌃q 退出           │
```

## 适合什么场景

- **同时推进多个 project。** 早上在 `my-app` 里让 Claude 排查一个线上问题，同时在 `my-api` 里让另一个 Claude 写接口。两边都在跑，侧栏上一眼看到谁还在干活（`●`）、谁已经跑完在等你（`◆`），选中就切过去，不用在一堆 iTerm2 标签页里翻。
- **一个 project 里开多个会话。** 同一个仓库里，一个会话做功能、一个会话写测试、一个会话专门问问题。它们都列在这个 project 下面，互不打扰。
- **接着之前的对话继续。** 侧栏列出 `~/.claude/projects` 里的历史会话，选中直接 `claude --resume`，不用去记会话 ID，也不用在 `/resume` 的列表里找。
- **关掉终端也不打断 Claude。** 会话跑在 atree 自己的 tmux 里，关掉 iTerm2 窗口、合上笔记本，Claude 继续工作；回来再敲一次 `atree`，一切都还在。
- **看看 Claude 改了什么。** 按一个键弹出当前仓库的改动：完整目录树里改过的、新增的、删除的文件用不同颜色标出，旁边是 diff。
- **会话多了也不乱。** 7 天没聊的会话自动收起，30 天没动的 project 自动归档，列表里只留下你最近在用的东西。

**和 claude-squad 的区别：** 侧栏是常驻的，和 Claude 对话时它一直在左边；所有 project 的会话都在同一个侧栏里；不会给会话建 git worktree 或分支，会话就在 project 原目录里开。

## 安装

### 1. 依赖

| 依赖 | 说明 |
|---|---|
| macOS + iTerm2 | 其他终端大多也能用，但只在 iTerm2 上验证过 |
| tmux 3.2+ | `brew install tmux` |
| Go 1.26+ | 用来编译 atree |
| Claude Code CLI | `claude` 命令在 PATH 里 |

### 2. 编译安装

直接从 GitHub 安装：

```bash
go install github.com/yudongnan23/atree/cmd/atree@latest
```

或者 clone 下来后在仓库目录里：

```bash
go install ./cmd/atree
```

可执行文件会装到 `~/go/bin/atree`。如果敲 `atree` 提示找不到命令，把下面这行加到 `~/.zshrc`：

```bash
export PATH="$HOME/go/bin:$PATH"
```

> 建议用 `go install` 装到固定位置，不要直接运行仓库里的 `./atree`：atree 的快捷键和侧栏会按这个路径调用自己。

### 3. 设置 iTerm2 的 Option 键（必需）

atree 的 `⌥←` `⌥→` `⌥d` 需要 Option 键发送 Esc 序列：

**iTerm2 → Settings → Profiles → Keys → General → Left Option key → 选 `Esc+`**

不设置的话，这几个快捷键不起作用。

## 快速上手

1. 打开一个**普通的** iTerm2 窗口（不要在 tmux 里），运行：

   ```bash
   atree
   ```

2. 左边出现会话列表，右边是提示界面。焦点在右边时，侧栏底部显示 `⌥← 回到侧栏  ⌃q 退出`。
3. 按 `⌥←` 把焦点移到侧栏，用 `↑↓` 选一个历史会话（`·` 开头），按 `⏎`：它会在右边 resume 出来，焦点自动跳到右边，可以直接打字。
4. 想换一个会话：`⌥←` 回侧栏 → 选另一个 → `⏎`。刚才那个会话在后台继续跑，前面的标记会变成 `●` / `◆` / `○`。
5. 想在某个 project 里开新会话：在侧栏把光标放在这个 project 上，按 `n`。
6. 想看 Claude 改了哪些代码：在右边的 Claude 里按 `⌥d`，看完按 `q`。
7. 要离开：按 `⌃q`。会话都还在后台；下次再运行 `atree` 回到原样。

## 界面说明

### 布局

- **左边：侧栏**，宽 34 列，常驻。
- **右边：当前会话**。每个 Claude 会话都是一个独立的 tmux 窗格，没显示的放在后台继续运行；切换就是把选中的那个换到右边。
- 当前有焦点的窗格有蓝色边框。侧栏有焦点时底部显示完整的按键提示，没焦点时只显示 `⌥← 回到侧栏  ⌃q 退出`。

### 侧栏里的行

| 行 | 样子 | 说明 |
|---|---|---|
| project | `▾ my-app` / `▸ my-api   3` | 黄色。`▾` 展开，`▸` 折叠（折叠时右边是会话数）。名字是目录名；两个 project 目录名相同时显示 `上级目录/目录名` |
| 会话 | `  ● 登录接口排查` | 标题取 Claude 的会话标题（`/rename` 设置的），没有则取最后一次提问。历史会话右边显示最后聊天日期 |
| 当前显示的会话 | 白色粗体 | 就是右边正在显示的那个 |
| 已归档的会话 | 标题变暗 | 收在「更早的」里，见下文 |
| 更早的会话 | `  … 更早的 6 个会话` | 7 天以前的会话和手动归档的会话折叠在这里 |
| 已归档 | `▸ 已归档   2` | 在列表底部，里面是被归档的 project |

### 状态标记

| 标记 | 颜色 | 含义 |
|---|---|---|
| `●` | 绿 | 正在干活 |
| `◆` | 红 | 跑完了一轮，你还没看过（类似 Desktop 的未读） |
| `○` | 蓝 | 在 atree 后台开着，空闲 |
| `↗` | 紫 | 在别的终端里运行（不是从 atree 开的）。选中时只会提示它的 pid，不会再开一个，以免两个进程同时写一个会话 |
| `·` | 灰 | 历史会话，未运行。选中即 resume |

## 快捷键

### 全局（任何时候）

| 按键 | 作用 |
|---|---|
| `⌥←` | 焦点回到侧栏 |
| `⌥→` | 焦点回到右边的 Claude |
| `⌥d` | 打开右边会话所在目录的 diff 浮窗（右边是提示界面时无反应） |
| `⌃q` | 退出 atree，回到普通终端。会话继续在后台运行 |
| 鼠标点击 | 点哪个窗格焦点就到哪；点侧栏里的行等于选中后按 `⏎` |

### 侧栏（焦点在侧栏时）

| 按键 | 作用 |
|---|---|
| `↑` `↓` / `k` `j` | 上下移动 |
| `⏎` | 会话行：打开（运行中的直接切过去，历史的 resume）。project 行 / 「更早的」行 / 「已归档」行：展开或折叠 |
| `→` | 展开 |
| `←` | 折叠；在会话行上按，会折叠它所在的 project 或「更早的」分组 |
| `n` | 在光标所在 project 的目录里开一个新会话 |
| `N` | 在一个新目录开会话（弹出输入框，见下表） |
| `x` | 关闭光标所在的会话（只对在 atree 里运行的有效），按 `y` 确认。聊天记录保留，之后还能 resume |
| `a` | 会话行：归档 / 取消归档这个会话。project 行：归档 / 取消归档这个 project |
| `d` | 打开光标所在会话 / project 目录的 diff 浮窗 |
| `esc` | 焦点回到右边的 Claude |

### 确认提示

关闭会话、归档正在运行的会话时，侧栏底部会出现 `(y/n)` 提示：按 `y` 确认，按其他任意键取消。

### `N` 新目录输入框

| 按键 | 作用 |
|---|---|
| 输入 | 目录路径，支持 `~` |
| `tab` | 补全路径（只补全目录）；有多个候选时列出最多 5 个 |
| `⏎` | 确定。目录存在就在那里开一个新会话；不存在会提示「目录不存在」 |
| `esc` | 取消 |

### diff 浮窗

| 按键 | 作用 |
|---|---|
| `↑` `↓` / `k` `j` | 在目录树里选文件（右边随之显示它的 diff） |
| `←` `→` / `⏎` | 折叠 / 展开目录；在文件上按 `←` 跳到它所在的目录 |
| `c` | 切换「只看改动」/「完整目录」 |
| `tab` | 在目录树和 diff 之间切换焦点 |
| `↑` `↓` / `k` `j`（diff 焦点） | 滚动 diff |
| `PgUp` `PgDn` / 空格 | 翻页 |
| `g` / `G` | 跳到 diff 开头 / 结尾 |
| `q` / `esc` | 关闭浮窗 |

## 常见用法

### 在两个 project 之间来回切

1. `⌥←` 到侧栏，选 `my-app` 下的会话，`⏎`。
2. 在 Claude 里布置任务，让它去跑。
3. `⌥←` 回侧栏，选 `my-api` 下的会话，`⏎`。
4. 侧栏上 `my-app` 那个会话显示 `●`，跑完会变成 `◆`。看到 `◆` 就切回去看结果。

### 同一个 project 开第二个会话

光标放在 project 行（或它下面任意会话）上，按 `n`。新会话出现在这个 project 下，标题先显示「新会话」，你提问后变成 Claude 起的标题。

### 在一个从没用过 Claude 的目录开会话

在侧栏按 `N`，输入路径（`tab` 补全），`⏎`。这个目录会作为新 project 出现在侧栏里。

### 继续一个上周的对话

找到那个 project，在 `… 更早的 N 个会话` 上按 `⏎` 展开，选中会话按 `⏎`，它会 resume 到右边。

### 收拾列表

- 不想再看到的会话：选中按 `a`，它收进「更早的」里。
- 告一段落的 project：选中 project 行按 `a`，整个 project 进「已归档」。以后在里面打开任意一个会话，它就自动回来。

### 检查 Claude 的改动

在右边的 Claude 里按 `⌥d`（或在侧栏选中会话按 `d`），左边目录树里黄色 `M` 是修改、绿色 `A` 是新增、红色 `D` 是删除，右边看 diff。按 `c` 只看改动过的文件，按 `q` 关闭回到 Claude。

## 折叠与归档规则

atree 的归档**只影响显示**，不删除、不修改 Claude 的任何文件。

### 排序

- project 按「最近一次聊天时间」从新到旧排，最近用的在最上面。时间取的是这个 project 下所有会话（包括已归档会话）中最新的那次更新。
- 同一个 project 里：正在运行的会话排前面，其余按最后聊天时间从新到旧。

### 7 天折叠

每个 project 下面直接显示：

- 最近 7 天内聊过的会话；
- 所有正在运行的会话（不管多久以前开始的）。

其他会话都收进 `… 更早的 N 个会话`。展开状态会记住，直到你再折叠它。

### 会话归档（会话行按 `a`）

- 会话**留在原来的 project 里**，收进「更早的」分组，标题变暗。
- 正在运行的会话：会先确认，确认后结束它再归档。在别的终端运行的（`↗`）不能归档。
- 打开一个已归档的会话会自动取消归档；也可以在它上面再按一次 `a`。

### project 归档（移到底部「已归档」）

- **自动**：一个 project 30 天内没有任何会话更新、并且没有会话在运行，就会自动进「已归档」。
- **手动**：在 project 行按 `a`。如果里面还有会话在运行，会提示「这个 project 还有正在运行的会话，请先关闭」，先用 `x` 关掉它们。
- **回来**：
  - 手动归档的：在「已归档」里的 project 行上再按 `a`；
  - 不管哪种：只要这个 project 里有了新的聊天（比如从「已归档」里打开一个会话），它就自动回到主列表。
  - 自动归档的 project 按 `a` 会提示「30 天内没有活动的 project 会自动归档，打开其中一个会话即可恢复」。
- 「已归档」里的每个 project 都可以单独展开，列出它的全部会话。

## diff 浮窗

- 打开方式：侧栏按 `d`，或在 Claude 里按 `⌥d`。浮窗占屏幕 90%，关闭后回到原来的位置，不影响任何会话。
- **顶栏**：`project 名 · 当前分支 · N 个文件修改，N 个新增，N 个删除`；没有改动时显示「没有未提交的改动」。
- **左边：完整目录树**（以仓库根目录为根）
  - 包含已跟踪文件、未跟踪但没被 `.gitignore` 忽略的文件、已删除的文件。
  - 黄色 `M` 修改，绿色 `A` 新增（含未跟踪），红色带删除线 `D` 删除；重命名显示为旧路径 `D` + 新路径 `A`。
  - 有改动的目录默认展开，并在名字后标出改动文件数；其他目录默认折叠。
- **右边：选中项的内容**
  - 修改 / 删除的文件：相对 `HEAD` 的 diff（暂存和未暂存的改动合在一起）。
  - 新文件：整篇显示为新增。
  - 未改动的文件：显示文件内容。
  - 目录：列出它下面改动过的文件。
  - 二进制文件显示「二进制文件」；超过 1 MB 的只显示前 1 MB；符号链接和子模块只显示说明。
- **只读**：不会暂存、提交或回滚任何东西，也不会写 `.git/index`，不会影响 Claude 同时进行的 git 操作。
- 注意：git 只知道目录**整体**的未提交改动，**分不清是哪个会话改的**；会话里已经 commit 的改动不会出现。

## 退出、升级与重启

| 想做的事 | 怎么做 |
|---|---|
| 暂时离开，会话继续跑 | 按 `⌃q`，或直接关掉 iTerm2 窗口 |
| 回来 | 再运行 `atree` |
| 结束某一个会话 | 在那个 Claude 里输入 `/exit`，或在侧栏选中它按 `x` |
| 结束所有会话 | 在任意终端运行 `tmux -L atree kill-server`（聊天记录保留，之后可在侧栏里 resume） |
| 升级 atree | 运行 `go install github.com/yudongnan23/atree/cmd/atree@latest`（或在仓库里 `git pull && go install ./cmd/atree`），然后再运行一次 `atree`：侧栏会自动换成新版本，正在运行的会话不受影响 |
| 电脑重启后 | 会话不会自动恢复。运行 `atree`，它们会以 `·` 历史会话出现，选中即可 resume |

## 从 ctree 迁移

atree 以前叫 ctree。改名后：

- 命令是 `atree`，tmux socket 是 `atree`，配置目录是 `~/.config/atree`，环境变量前缀是 `ATREE_`。
- 第一次运行 `atree` 时，会自动把 `~/.config/ctree/state.json`（归档、折叠等状态）复制到新目录。
- 旧的 `ctree` tmux server 里开着的会话不会出现在 atree 里。建议先在旧 ctree 里把会话 `/exit` 掉（或运行 `tmux -L ctree kill-server`），再在 atree 里 resume 它们——聊天记录不会丢。
- 确认不再需要后，可以删除旧文件：`rm ~/go/bin/ctree`、`rm -r ~/.config/ctree`。

## 常见问题

**`⌥←` / `⌥→` / `⌥d` 没反应？**
iTerm2 的 Left Option key 没设成 `Esc+`，见[安装第 3 步](#3-设置-iterm2-的-option-键必需)。

**在 Claude 输入框里 `⌥←` 不能按单词左移了？**
这是预期的：atree 用 `⌥←` 回到侧栏，用 `⌥d` 打开 diff。在输入框里移动光标请用其他方式。

**运行 `atree` 提示「atree 不能在 tmux 里运行」？**
你在一个 tmux 会话里。请在普通的 iTerm2 窗口里运行。

**某个会话显示 `↗`，点了只提示 pid？**
这个会话是在别的终端里直接用 `claude` 开的。想用 atree 管理它：先在那个终端里退出（`/exit`），再回到 atree 里选中它按 `⏎`。

**升级后新快捷键不生效（比如在 project 上按 `a` 没反应）？**
你看到的可能还是旧版侧栏。按 `⌃q` 退出，再运行一次 `atree`，侧栏会换成新版本。

**右边空了 / 侧栏不见了？**
右边的 Claude 退出后，atree 会在一秒内补上提示界面。侧栏如果崩溃会自动重启；万一没回来，`⌃q` 退出后再运行一次 `atree`。

**在 project 行按 `a`，提示「还有正在运行的会话」？**
有正在运行会话的 project 不能归档。先用 `x` 关闭这些会话（`↗` 的需要到它所在的终端里退出）。

**diff 浮窗提示「这个目录不是 git 仓库」？**
这个会话所在的目录不在任何 git 仓库里。

## 限制

- 不能在 tmux 里运行 atree。
- 不支持 iTerm2 的 `tmux -CC` 集成模式。
- 只支持 Claude Code，暂不支持 Codex 等其他工具。
- 会话数据读自 Claude Code 未公开的文件格式（`~/.claude/sessions`、`~/.claude/projects`），Claude Code 升级后可能需要适配；相关代码集中在 `internal/claudedata`。
- 7 天 / 30 天的阈值目前不可配置。

## 文件与环境变量

| 路径 | 内容 |
|---|---|
| `~/.config/atree/state.json` | 归档、折叠/展开、最后查看时间 |
| `~/.config/atree/tmux.conf` | atree tmux server 的配置，每次运行 `atree` 时重写并重新加载 |

atree 只**读取** `~/.claude`，从不修改它；也不读不改你自己的 `~/.tmux.conf` 和默认 tmux server。

| 环境变量 | 作用 | 默认 |
|---|---|---|
| `ATREE_SOCKET` | atree 使用的 tmux socket 名 | `atree` |
| `ATREE_CONFIG_DIR` | atree 状态和配置目录 | `~/.config/atree` |
| `ATREE_CLAUDE_DIR` | Claude Code 数据目录 | `~/.claude` |

代码结构：

| 目录 | 职责 |
|---|---|
| `cmd/atree` | 命令入口：`atree`、`atree sidebar`、`atree placeholder`、`atree diff <dir>`、`atree diff-slot` |

| `internal/tree` | 把会话、窗格、状态合成侧栏的行（纯函数，含折叠/归档规则） |
| `internal/ui` | 侧栏界面（Bubble Tea） |
| `internal/tmux` | 驱动 atree 的 tmux server，以及 tmux 配置 |
| `internal/state` | atree 自己的状态文件 |
| `internal/gitdiff` | 只读地读取 git 改动 |
| `internal/diffui` | diff 浮窗界面 |

设计文档在 `docs/superpowers/specs/`，实现计划在 `docs/superpowers/plans/`。
